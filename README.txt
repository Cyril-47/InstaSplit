
  ╔══════════════════════════════════════════════════════════╗
  ║           InstaSplit — Seamless Carousel Studio          ║
  ╚══════════════════════════════════════════════════════════╝

  Split panoramic & wide images into seamless Instagram
  carousel posts. 100% client-side, offline-ready, no uploads.


  ─────────────────────────────────────────────────────────
   GETTING STARTED
  ─────────────────────────────────────────────────────────

  Option A — Open directly
    Double-click  index.html  to open in your browser.

  Option B — Install as a desktop app (recommended)
    1. Serve the folder locally:
         python -m http.server 8080
    2. Open  http://localhost:8080  in Chrome or Edge.
    3. Click the "Install App" banner at the top, or use
       the browser install icon (⊕) in the address bar.
    4. InstaSplit now launches from your desktop like a
       native app and works fully offline.


  ─────────────────────────────────────────────────────────
   KEYBOARD SHORTCUTS
  ─────────────────────────────────────────────────────────

   Ctrl + O        Open file picker
   Ctrl + V        Paste image from clipboard
   Ctrl + S        Export / download carousel ZIP
   Ctrl + R        Reset crop position & zoom
   Ctrl + F        Auto-fit image to viewport

   +  /  -         Zoom in / out (quick step)
   Scroll Wheel    Zoom in / out on canvas (pointer-centered)

   ←  /  →         Navigate preview slides (left / right)


  ─────────────────────────────────────────────────────────
   MOUSE CONTROLS
  ─────────────────────────────────────────────────────────

   Drag            Pan the image inside the crop area
   Scroll Wheel    Zoom centered on your cursor position
   Swipe on Phone  Preview carousel transitions in the
                   phone mockup simulator


  ─────────────────────────────────────────────────────────
   TIPS
  ─────────────────────────────────────────────────────────

   • Use wide panoramic photos (e.g. 2880×1620) for best
     results with seamless transitions.
   • Set slide count to 3–5 for the ideal Instagram swipe
     experience.
   • Choose 4:5 Portrait for maximum screen real estate on
     mobile feeds, or 1:1 Square for a classic grid look.
   • Export quality defaults to 90% JPEG — bump to 100%
     if file size is not a concern.
   • Do NOT apply Instagram filters after uploading, as
     they can break the seamless transitions between slides.
